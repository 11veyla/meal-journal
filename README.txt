MEAL JOURNAL V2
1. 解压 ZIP，将 index.html、manifest.webmanifest、sw.js、icons 文件夹上传到 GitHub 仓库根目录。
2. GitHub Pages 选择 main 分支 / root。
3. Android Chrome：菜单 > 安装应用；iPhone Safari：分享 > 加入主屏幕；电脑 Chrome/Edge：地址栏安装图标或菜单 > 安装页面为应用。
4. 本地记录使用 IndexedDB。请定期导出 JSON 备份。
5. 云端同步尚未接入，需要后续配置云端数据库。
6. 可替换 icons/icon-192.png 与 icon-512.png，文件名和尺寸保持不变。
